# Firma con CIE 1.0.2

Versione in preparazione, non ancora pubblicata. La build locale macOS per il
collaudo è firmata Developer ID Application e non è stata notarizzata.
La distribuzione finale macOS tramite Actions richiede firma e notarizzazione
secondo il workflow già configurato.

## Modifiche

- Il solo pacchetto macOS da pubblicare è il DMG Universal; lo ZIP dell’app
  non viene aggiunto alla bozza della release.
- I nomi dei pacchetti di installazione indicano il sistema di destinazione:
  `windows`, `macOS` o `linux`. Gli identificativi interni dei pacchetti Linux
  e il nome dell’app installata rimangono invariati.
- La finestra «Informazioni su Firma con CIE» di macOS mostra soltanto la
  versione pubblica. La build interna rimane disponibile nei metadati.
- Rimossa la voce «Informazioni e licenze» dal fondo della Guida.
- Aggiunto «Pagina del progetto Firma con CIE» nella pagina Informazioni,
  prima di «Licenze e riconoscimenti», con apertura nel browser predefinito
  e testo disponibile in italiano e inglese.

## Pacchetti previsti

| Sistema | Esempio di nome |
| --- | --- |
| macOS Apple Silicon e Intel | `firma-con-cie_1.0.2_macOS_universal.dmg` |
| Windows x64 | `firma-con-cie_1.0.2_windows_x64_setup.exe` |
| Windows ARM64 | `firma-con-cie_1.0.2_windows_arm64_setup.exe` |
| Linux DEB | `firma-con-cie_1.0.2_linux_ubuntu_amd64.deb`, `firma-con-cie_1.0.2_linux_ubuntu_arm64.deb` |
| Linux AppImage | `firma-con-cie_1.0.2_linux_ubuntu_x86_64.AppImage`, `firma-con-cie_1.0.2_linux_ubuntu_aarch64.AppImage` |
| Linux Fedora | `firma-con-cie_1.0.2_linux_fedora_x86_64.rpm`, `firma-con-cie_1.0.2_linux_fedora_aarch64.rpm` |
| Linux Arch | `firma-con-cie_1.0.2_linux_arch_x86_64.pkg.tar.zst` |

Sorgenti, dipendenze corrispondenti e checksum `.txt` sono raccolti nella bozza
della release; i rapporti JSON restano nella bozza tecnica privata. Nessuna release precedente viene modificata.
Le build complete delle altre piattaforme e il collaudo utente della nuova
interfaccia restano da eseguire prima della pubblicazione.
